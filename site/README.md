# ATTLAW landing

Landing estática de exploración para ATTLAW. El sitio usa los recursos de `../brand/` y copias locales dentro de `dist/assets/`. Para verlo localmente: `python -m http.server 4173 --directory dist` desde esta carpeta y abrir `http://localhost:4173`.

La página presenta una dirección visual y no afirma estadísticas, clientes ni controles de seguridad aún no documentados. Los enlaces recorren secciones de la misma página. Antes de publicar una llamada comercial, conectar un canal real de contacto.

## Rediseño v2 (nov 2026)
- Layout horizontal que usa todo el ancho: hero partido, tira de estaciones, "camino" en zigzag con trazo cobre, escena a sangre, principios en 4 columnas y fila de personas.
- Tipografía: Noto Serif (OFL) para titulares y Manrope para interfaz, ambas locales en `dist/fonts/`.
- Pendiente de validar: los "Principios" (reserva, trazabilidad, acceso por función, continuidad) son criterios de diseño, no controles certificados. Confirmar con el producto real antes de publicar. Sigue sin haber canal de contacto real.
